# Danh sách kích hoạt tool — BẢN DỰ PHÒNG

Đây là bản sao dự phòng của danh sách kích hoạt dùng cho các tool Flow của Sơn Tool
(Affiliate, Edit, và các tool sau này).

Cách hoạt động: mỗi tool tự tra danh sách này (cùng bản chính trên HuggingFace)
mỗi lần mở. Máy khách đã kích hoạt + còn hạn thì tool mở thẳng, không hiện lại
bảng nhập key sau khi tải lại trang. Bản chính lỗi thì bản dự phòng này gánh
thay tự động — khách không nhận ra sự khác biệt.

Mỗi dòng trong registry.json = 1 key đã cấp: key + mã máy + tool + trạng thái.
Key chỉ dùng được trên đúng máy của nó nên danh sách này để công khai vẫn an toàn.

File dữ liệu: registry.json (ở thư mục gốc repo này).
